# Hora de Sair - API

API simples para calcular o horário de saída de uma jornada.

## Como executar

```bash
pip install -r requirements.txt
python app.py
```

API: `http://127.0.0.1:5000`

Swagger: `http://127.0.0.1:5000/apidocs/`

## Rotas

- POST `/calculos`
- GET `/calculos`
- GET `/calculos/<id>`
- DELETE `/calculos/<id>`
